# 2026-VK-EDU-Web-11-Vorontsov-S
Для просмотра откройте файл `public/index.html` в любом браузере или запустите через расширение Live Server в VS Code.

## Список страниц и роутов
- `index.html` — Главная страница (список вопросов, пагинация, сайдбар с тегами и лучшими пользователями).
- `ask.html` — Страница создания нового вопроса.
- `tag.html` — Страница тега (работает только python)
- `question.html` — Страница детального просмотра вопроса со списком ответов и формой добавления ответа.
- `settings.html` — Страница редактирования профиля и настроек пользователя.
